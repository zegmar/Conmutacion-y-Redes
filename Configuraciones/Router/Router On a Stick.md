interface [interfaz].[subinterfaz]

Crear una subinterfaz virtual en el router, una por VLAN (Router-on-a-Stick).

encapsulation dot1Q [vlan_id]

Etiquetar el tráfico de la subinterfaz para una VLAN específica.

encapsulation dot1Q [vlan_id] native

Indicar que esa subinterfaz atiende a la VLAN nativa.

ip address [IP] [máscara]

En una subinterfaz, la IP es el Default Gateway de esa VLAN.
