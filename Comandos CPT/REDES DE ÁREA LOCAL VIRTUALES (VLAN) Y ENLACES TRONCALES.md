- vlan # n: Crea una vlan.

```ad-info 
title: Etiqueta de VLAN
Se etiqueta la vlan con name nombre

```

- Switchport Access vlan num: Da acceso a los puertos a una vlan seleccionada.

- switchport access: Configura la interfaz en modo de acceso estático para que pertenezca a una única VLAN (se complementa indicando el número de VLAN).

- switchport mode trunk: Cambia el puerto del switch a modo troncal para vincular conexiones a otro switch.

- switchport trunk allowed vlan num: Indica las vlans permitidas de un enlace troncal.

- switchport trunk nativa vlan 99: Se indica la vlan nativa del enlace troncal del switch.

- Interface vlan 1: Entra a la configuración de la interfaz vlan 1.

- ip address dirección ip mask: Asigna dirección IP a la interfaz.
