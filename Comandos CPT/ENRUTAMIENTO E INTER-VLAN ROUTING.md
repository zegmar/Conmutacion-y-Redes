- ip default-gateway ip: Asigna la IP del gateway por default.

- interface FastEthernet 0/0.10: Entra al sub-interfaz de un puerto del switch.

- encapsulation dot1q vlan: Configura el protocolo IEEE 802.1Q para identificar a qué vlan pertenece el tráfico que pasa por una interfaz.

- encapsulation dot1q vlan native: Configura una vlan como nativa en la subinterfaz del router.

- ip routing: Habilita el enrutamiento IP en un switch de capa 3 y permite enrutar paquetes entre distintas vlans.

- no switchport: Hace que el puerto del switch de capa 3 no se comporte como switch de capa 2.
